## 先修正驗收語意，再量測

| v4 原基準 | v5 必須採用的判定 |
|---|---|
| HP=0 仍可移動／射擊，是刻意政策 | HP=0 進死亡；禁止玩法效果，180 Tick 後依契約自動重生 |
| 一個 Session 的 HP 單調降至 0 | 按 PlayerId／lifeGeneration 核對生命開始、傷害、死亡與重生；新生命滿血不是作弊回血 |
| 無限彈藥、20 Tick 冷卻 | 12 發彈匣、無限備彈、10 Tick 冷卻；90 Tick 合法完成才補彈 |
| 乾淨測試零 epoch 重設 | 零**非預期恢復**重設；契約要求的 respawn epoch 另計並逐次核對，不能掩蓋 backlog reset。持續相位追蹤在 stall reseed 後重新取得相位不是 epoch 重設，另列其次數與 acquiring 秒數（2026-10-02） |
| 死後持續對零血角色射擊 | 全程覆蓋多生命、合法射擊與換彈；另設死者／舊生命／空彈等預期拒絕案例 |
| 只按已觀察到的可用事件算通過率 | 執行前固定操作排程、事件分母與資格；死亡、換彈、漏收或失配不能事後刪除 |

上述是新契約的明確替換，不把 v4 已通過的政策重新描述為當時的缺陷。
來源／分析器更改後，歷史 v4 報告仍只證明原版本。

每條生命都要核對 HP 初值與唯一傷害累積、射擊扣彈、換彈開始／完成／取消、
死亡和重生各一次；完整 Snapshot 與 HUD 同樣核對，不能只看終局數字。
同 Session 的 ActionId 跨 lifeGeneration 延續；已裁決結果不可變，未裁決的失效生命動作
取得 terminal 拒絕、交付及退休。重生不是清空未知裁決的理由。
舊生命失效而未執行的移動命令另列生命週期取消，不算 Actual，也不能靜默消失。

測試應在執行前記錄各類預期事件及命名分母：移動、跳躍、合法射擊、換彈、死亡、
重生、故意非法動作、可見交越。若某合法排程因前提失敗變成非法，報為測例失敗
或明確受干擾，不能事後降低分母。未配對／未知事件保留並按既定規則計入。
一般移動延遲測例保持玩家存活、無 reload 等不相關前提，另列完整生命週期整合；
兩者都必須實際驗證，不能讓純移動通過抵銷完整玩法失敗。

## 固定量化門檻

本批不放寬 v4 的移動與交付門檻；玩法變更不構成調低門檻的理由。

| 指標 | 通過門檻 |
|---|---|
| 移動產生 → 首次成功送出 | P95 ≤22 ms |
| 移動產生 → Actual | P50 ≤50 ms，P95 ≤66.7 ms |
| 原始移動命令 Actual 比例 | 暖機後 ≥99%，分母事前定義 |
| 跨視窗移動交越 | P50 ≤50 ms，P95 ≤80 ms |
| 移動事件配對率 | ≥99%；未配對／不明按無限延遲計入 |
| 本機射擊回饋 | 下一個成功 Presented 幀開始，不等待裁決 |
| 射擊產生 → Match 裁決 | 乾淨同機 P95 ≤100 ms |
| 射擊產生 → Client 取得裁決 | 乾淨同機 P95 ≤150 ms |
| 動作正確性 | 每 Session／ActionId 至多一次效果；每生命傷害／彈藥與唯一裁決一致 |
| 非法效果 | 過期、冷卻、空彈、換彈中、死亡或舊生命等拒絕零玩法效果 |
| 裁決及移動恢復 | 生還、可操作且有效 Session 在干擾解除後 1.5 秒內恢復；移動穩定觀察至少 250 ms |
| 容量／排程 | 動作窗口 ≤32，批次 ≤8，完整 UDP ≤1,200 bytes；既有限流／送出頻率不提高 |
| 診斷與重設 | 零靜默遺失；respawn 與非預期恢復 epoch 分列，保留全部慢幀與拒絕原因 |
| 相位追蹤（2026-10-02） | 計次 GUI 輪記錄量測期間 tracking／acquiring 秒數、修正與遲到修正次數；量測期間處於 acquiring 須說明原因，不得省略 |
| 連線品質移出（2026-10-02） | 可控邊界內的情境零移出（誤踢）；越界情境（RTT 約 150 ms 以上或低於 30 FPS）依契約約 40 秒內移出，Client 回 Lobby 並顯示原因，其他玩家不受影響 |

正常合法節奏、10 Tick 邊界、快速連按壓力與故意拒絕分開報告。不能用低頻的
原 v4 合法射擊長測證明新 10 Tick 節奏已驗收；正常測例仍需預留已記錄的排程餘量，
精確權威 Tick 邊界由 domain 測例判斷。只在同機比較單調時鐘，不稱 input-to-photon。
死亡的 3 秒玩法等待與出生點阻塞另列生命驗收，不能藉此放寬生還玩家的恢復門檻。

## 網路與生命週期必需證據

第 03 批的共存與恢復是必要前提，不是可選附錄。若正式版本或相關分析器改動，
依影響補驗以下短例，不能只用 GUI 能玩作為交付證明：

- 真 HTTP／UDP／TCP，RTT 0／20／40 ms、最多 10 ms 單向抖動、5% 丟包、
  burst 兩包遺失；首請求、裁決及 ACK 遺失、重複、亂序、同 ID 內容衝突。
- 既有上／下行、Gateway、Host IPC 等 250 ms／1 秒阻塞，以及 Client 主執行緒
  停頓、movementEpoch 恢復、離開／重入、Session 到期與斷線清理。
- 干擾跨換彈完成、死亡及重生；舊生命未決動作 terminal 拒絕，舊裁決可確認退休，
  不回寫新生命 HP／ammo／HUD、不重開動畫，不讓帳本永久卡住。
- 連線品質移出（2026-10-02）：HUD 警告出現與倒數、連續 3 窗口不合格後移出、Gateway 清除保留並回傳
  `evicted_high_latency`／`evicted_unstable_input`、被移出者可重新加入；同局另一玩家的移動與動作不中斷。
- 正常與故障跑次分開報限流、拒絕、移動 Actual、窗口與積欠趨勢；故障後收到
  任意舊快照不算恢復，必須有新的合法操作裁決及持續移動。
