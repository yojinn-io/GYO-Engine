# v7 事故紀錄（Incident）

這個資料夾記錄 PvP v7 開發中發生的事故：量測基準、資訊流或工作流程出了問題，讓我們在錯誤的前提上做了決定或花了大量時間的事件。

- 每份紀錄一個檔案，檔名是 `YYYY-MM-DD-簡短名稱.md`（日期是事故被認定的那一天，JST）。
- 每份紀錄的結構：摘要、狀態與嚴重度、影響、時間線、根因、流程上的因素、偵測、處置與行動項目、學到的事、證據位置。
- 紀錄以事實為主，推論標「推論」；寫流程上的因素時不歸咎個人。
- 決策本身仍記在 `../HANDOFF.md` 的決策紀錄；這裡記的是經過、原因與之後怎麼做，並連回對應的決策。
- 狀態：**處置中**（根因已確認、修正或重做未完成）、**已解決**（修正已合併、受影響的工作已重做或註明）、**已結案**（行動項目全部處理完）。行動項目完成時，更新紀錄的狀態與本索引。
