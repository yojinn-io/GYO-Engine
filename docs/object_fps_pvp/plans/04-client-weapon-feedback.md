實作與原始證據見 [本批 dev_log](../../dev_logs/2026_09_28_pvp_v4_batch04.zh-Hant.md)。

## 目標

接入既有 Mark23 模型、材質及動畫，形成「按下射擊 → 即時本機回饋 → 權威命中與
扣血」。不增加第三人稱槍模、聲音系統、子彈物件或回溯。

## 實作

- 使用產品現有 WeaponViewModel、Mark23、Idle／Draw／Shoot；只納入必要模型、
  圖片與動畫依賴，不將完整 Campaign、彈匣或換彈玩法帶入 PvP。
- 可操作前完成槍模準備，避免第一槍同步載入資產。射擊參數讀 Match 下發規則。
- 左鍵上升沿最多一個 ActionId；按住不連發，30 FPS 多固定步不重複產生。
  本機冷卻是預判，最終接受由 Match 決定。
- 第一次點擊只捕捉滑鼠；Tab 釋放、失焦、拖窗停止新動作，已送動作繼續等原裁決。
- 每個已提交動作只播一次動畫／後座，重送、ACK、移動 replay 不重播。
  動作窗口滿時不建立新 ID 或留下未送出的 ID 缺口。
- 命中標記只由接受且命中玩家的裁決觸發。HUD HP 只取最新權威戰鬥狀態，晚到
  裁決不能倒退 HP。拒絕顯示短狀態，不倒放動畫。
- 後座只改武器呈現，不重複消費滑鼠 delta 或改變已提交的瞄準角。

## 短測與完成條件

- GPU 核對模型、材質、動畫、深度及視窗縮放。
- 30／60／144 FPS：一按一次動作／一次動畫；本機動畫不等待裁決。
- 雙 GUI：命中、遮牆、扣血、冷卻拒絕、HP=0 仍操作、Esc 重入滿血。
- 失焦／Tab／拖窗無幽靈射擊，重入無舊動畫／裁決；移動、轉向、射擊同時操作
  仍維持每幀只消費一次滑鼠 delta。
- 交付可試玩 Client 與短測證據；更新進度／交接後停止，不自動長測。

## 完成記錄

- 使用既有產品 WeaponViewModel／Mark23，新增呈現用 Idle／Draw／Shoot 介面，
  不編入 Campaign、彈匣或換彈控制。加入前完成模型、圖片、GPU 資源及 pipeline 暖機。
- 原生左鍵上升沿提交一次；捕捉點擊、按住、失焦／Tab／移動視窗事件不產生額外射擊。
  動作與移動重播分離，權威命中／拒絕各自呈現，HP 使用最新快照。
- 30／60／144 FPS 雙 GUI 操作、五張 GPU 圖像與 16 秒跨視窗延遲共五案通過。
  21 個 SDL 射擊都有下一個成功呈現幀；20 個移動事件全配對，P95 48.84 ms。

  native window 事件由 probe 注入；不是人工拖曳／OS 整機停頓根因的證明。
- 既有 120 秒／200 事件驗收入口與門檻保留，本批只跑顯式短模式，不冒充完整驗收。
