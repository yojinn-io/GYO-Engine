# v7.1 事故紀錄（Incident）

這個資料夾記錄 PvP v7.1 期間認定的事故。格式沿用 [v7 的事故紀錄](../../v7/Incident/README.md)：每份紀錄一個檔案，檔名是 `YYYY-MM-DD-簡短名稱.md`（日期是事故被認定的那一天，JST）；結構是摘要、狀態與嚴重度、影響、時間線、根因、流程上的因素、偵測、處置與行動項目、學到的事、證據位置；推論標「推論」，不歸咎個人。決策本身記在 [交接](../HANDOFF.md)。

- **量測／流程事故**：量測基準、資訊流或工作流程出了問題，讓我們在錯誤的前提上做了決定或花了大量時間（v7 的定義）。
