## 執行規則

- 使用者啟動每一批；Agent 自主完成該批的實作、建置、必要短測與交接，之後停止。
- 不自動開始下一批或提交 commit。原先不代跑長測的限制，已由本次追加授權解除；
  授權限於第 05 批完整驗收及必要修復，不擴大玩法或架構範圍。
- 批內實作細節及一般缺陷直接處理。若需要改協定語意、玩法、架構邊界、門檻或
  擴大驗收，先提出證據、選項及代價，再由使用者決定，不能默默更改契約。
- 發現前批缺陷時先補最小回歸；仍在既定契約內的修正記入交接。契約本身有問題
  則暫停依賴該決策的工作，不以大量全面重測代替判斷。
- 每批結束更新本表、HANDOFF 與該批 dev_log：修改、驗證、限制、未解問題、下一步。
- 大量結果先由腳本聚合，只讀摘要及異常片段。本次 Agent 已依序完成長測並核對
  完整證據；手動指令、退出碼及回報表保留供未來測試用例參考。

## 已批准的範圍

v4 完成單發手槍、無限彈藥、Match 當前狀態命中與扣血、動作去重／確認，以及現有
Mark23 模型動畫。本機回饋可預判，命中與血量只由權威決定。血量歸零仍可操作，
離開重入恢復滿血。

不包含死亡／重生、換彈、射擊回溯、同步範圍／增量編碼、公共同步框架。後續先做
時間對齊與歷史命中，再依量測做規模最佳化；第二個產品驗證共同需求後才抽共用機制。
