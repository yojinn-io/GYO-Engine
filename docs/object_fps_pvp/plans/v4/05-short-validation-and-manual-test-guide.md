## 目視／視窗試玩清單（保留供手動參考）

1. 移動、轉視角及兩者同時操作仍順暢。
2. 首次點擊捕捉滑鼠不開槍；之後單擊即有動畫，按住不連發。
3. 對準玩家的有效命中每次扣 25，四次後 HP=0；隔牆不扣血，未命中沒有命中標記。
4. HP=0 仍可操作；Esc 重入恢復滿血。
5. Tab、失焦及標題列拖曳不造成幽靈射擊／持續移動。
6. 移動、瞄準、射擊同時操作沒有新增卡頓。

目視不能替代分位數、重複效果或完整裁決統計，也不證明歷史整機停頓根因已修復。

## Probe 的量化門檻

| 指標 | 通過門檻 |
|---|---|
| 移動產生 → 首次成功送出 | P95 ≤22 ms |
| 移動產生 → Actual | P50 ≤50 ms，P95 ≤66.7 ms |
| 原始移動命令 Actual 比例 | 暖機後 ≥99% |
| 跨視窗移動交越 | P50 ≤50 ms，P95 ≤80 ms |
| 移動事件配對率 | ≥99%；未配對／不明者按無限延遲計入 |
| 本機射擊動畫 | 下一個成功呈現幀開始，不等待裁決 |
| 射擊產生 → Match 裁決 | 乾淨同機 P95 ≤100 ms |
| 射擊產生 → Client 取得裁決 | 乾淨同機 P95 ≤150 ms |
| 重複效果 | 每 ActionId 最多一次接受／傷害效果，零重複扣血 |
| 非法效果 | 過期、冷卻中、非法身分零傷害 |
| 裁決完整性 | 有效 Session 干擾解除後 1.5 秒內收斂，未知結果不得忽略 |
| 容量／封包 | 動作窗口 ≤32，批次 ≤8，完整 UDP ≤1,200 bytes |
| 移動恢復 | 延續 v3：1.5 秒內恢復並維持至少 250 ms 穩定觀察 |
| 診斷 | 零靜默遺失，保留全部慢幀與拒絕原因 |

射擊延遲包含接受與拒絕並另報接受率；正常射速以至少 400 ms 間隔測試，冷卻壓力
測試另報，不混在一起提高接受率。正常乾淨場景的合法射擊應全部取得裁決並被接受。
各階段記錄同一動作識別；只在同機比較單調時鐘，不宣稱 input-to-photon。

## 完整測試與保留的手動入口

- 提供核對過參數的可複製命令，包含 Match、Gateway、probe、Arena 與新輸出目錄；
  不要求使用者拼裝路徑。使用既有 timing runner 及產品射擊 probe，不建立通用測試平台。
- GUI 三輪，各 120 秒／200 移動事件，射擊／HP 同時存在；三輪分別達標，
  不合併掩蓋失敗。
- Headless 網路／預測以 60／144 Hz 各實時 30 分鐘，加入合法固定射擊節奏；
  輸出移動產消、動作產消、裁決、拒絕、重複效果、窗口／積欠趨勢。
- 乾淨長測零非預期 epoch 重設、零診斷遺失、零模擬掉時及零持續窗口凍結。
  故障注入或 ≥100 ms 排程停頓須保留資料並標為受干擾，不算乾淨通過，不無限重跑。
- 程序結束一次輸出 JSON 摘要、可讀報告及退出碼。本次由 Agent 核對實際結果；
  未來手動執行時可使用相同命令及回報欄位，回傳摘要／異常片段供分析。
- 明示 headless 長測不是 GUI 長測；v4 未回溯，移動目標的顯示位置與當前權威
  位置不同仍屬下一階段。真正網卡 LAN、Windows 與 OS 拖窗根因不得冒充已驗證。
