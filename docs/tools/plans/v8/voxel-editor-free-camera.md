## 範圍

### C1 自由相機（飛行）

- **兩種相機，可以切換**：
  - 現在的繞點相機（orbit）照舊。
  - 新增自由相機（free）。
  - 切換鍵：**Tab**（現在沒用到）。面板的「檢視與相機」組也有切換鈕。
- **自由相機的操作**（照常見 3D 編輯器的「按住右鍵飛行」）：
  - **按住右鍵**：滑鼠移動改視線方向（水平轉、上下看，俯仰限制在 ±1.5 rad，和 orbit 一樣）。
  - **按住右鍵時**：
    - W／A／S／D：前後左右移動（沿視線的水平方向與右方）。
    - E／Q：上升／下降。
    - Shift：4 倍速。
    - 這些鍵在按住右鍵時**只當相機鍵**，不切換工具、不轉朝向（S＝Shape、Q／E＝朝向的衝突因此避開）。放開右鍵後恢復原本的用途。
  - **滾輪**：調整移動速度（每格 ×1.25；範圍 1～256 格／秒；預設 8 格／秒）。自由相機沒有「縮放」。
  - **左鍵**：照舊編輯；拾取從自由相機發出。
- **切換時畫面不跳**：
  - orbit → free：沿用 orbit 當下的相機位置與視線。
  - free → orbit：保持位置與視線，注視點放在「視線碰到的第一個方塊」；碰不到時，放在前方 16 格。
- **自由相機的繪製距離**：
  - 中心是相機位置（遊戲端的做法；ve-cull 宣告第 4 點）。
  - 距離用面板的繪製距離，不跟著縮放擴大。
  - 2,000 區塊的上限照舊。

### C2 穿牆時的顯示（H5）

- **自由相機的 near 裁切面拉到 0.5 格**：
  - 貼著牆或在格子之間穿過時，緊貼相機的面被 GPU 裁掉，不會整面擋住畫面。
  - 只改相機參數，不改區塊內容（DI 7 不受影響）。
- **orbit 不動**（現況的 near＝距離 × 0.01）。
- **剖面（只畫某高度以下）不在本批**：
  - 要做到逐格精確，需要 Render 的裁切平面（Render owner，要找架構師）；用區塊級剔除只能到 16 格的精度。
  - 先看自由相機夠不夠，不夠再另外宣告。

## 不改

- framework 的 `OrbitCamera`：自由相機只在這個工具用，放在工具裡（共通功能等觀察到第二個使用者再放進 framework；目前沒有）。
- DI 1～7、格式、Engine。
- 現有的鍵：都不改，只在按住右鍵時讓出 W／A／S／D／Q／E。

## 契約影響

- DI 1：
  - 自由相機的數學（位置、yaw、pitch、移動、轉成 `CameraPose`）放在核心，只用 `GYO::Math`。
  - 視窗把它轉成 Render 的相機。
- DI 7：near 裁切面只是相機參數。

## 判定

| 代號 | 判定 | 根據 |
|---|---|---|
| FC1 | 自由相機的數學：<br>前進沿視線的水平方向、右移垂直於它、E／Q 只改高度；<br>俯仰限制 ±1.5；<br>速度範圍 1～256、滾輪 ×1.25；<br>Shift 4 倍 | CPU 規則測試＋突變 |
| FC2 | 切換不跳：orbit → free 的 `CameraPose` 等於 orbit 的；free → orbit 的位置與視線不變，注視點在第一個方塊，碰不到時在前方 16 格 | CPU 規則測試＋突變 |
| FC3 | 按住右鍵時，W／A／S／D／Q／E 不切工具、不轉朝向 | 把「這個鍵現在是相機鍵還是編輯鍵」寫成純函式，CPU 測試；畫面上的操作在 L3 |
| FC4 | 本機 `cpu|shader` 全部通過；L1 三平台通過 | CI |
| L3 | 你用自由相機飛進 building 的上層，在室內放、刪方塊；貼牆時不被整面擋住；Tab 來回切換不跳。合格與否由你判斷 | 試用 |

- 不加新的量測：自由相機畫的區塊數受同一個 2,000 上限，成本和 ve-feel-1 的 E4 同量級。
