# 例行健檢（Checkup）

本目錄記錄定期健檢的結果。健檢分成兩種，各有自己的資料夾、判斷標準、步驟與報告列表，由不同的會話負責：

| 資料夾 | 內容 | 負責 |
|---|---|---|
| [architecture/](architecture/README.md) | 架構漂移健檢：Engine 是否被產品入侵，以及該由 Engine 負責的功能是否落在別處 | 架構會話 |
| [documentation/](documentation/README.md) | 文件健檢：斷鏈與錨點、與程式碼不符的過時內容、狀態與 git 紀錄是否一致、各語言版本、繁中用字 | 文件整理會話 |

兩種健檢共同的規則：

- 每份報告以日期命名，只記錄當時 commit 的觀察，不回頭改寫；後續狀態寫進下一份報告。
- 健檢只產生觀察與建議，不直接觸發重構。是否立案、何時處理由使用者決定（AGENTS.md §11、§13）。
