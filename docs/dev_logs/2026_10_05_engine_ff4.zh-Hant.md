# Engine FF-4：Color 有限性檢查收斂

日期：2026-10-05。**完成**（PR 待開）。分支 `claude/engine-ff4`，疊在 FF-1 上。
計畫見 [基礎後續整理 PLAN 的 FF-4 節](../architecture/plans/foundation-followups/PLAN.md)。

## 開始

接續使用者「把 Engine 側的功能完成」的指示。檔位 high，不用 ultracode。
計畫建議本批在 IP-2 之後合併（`SdlGpuRenderDevice.cpp` 衝突），這不是依賴；本批先完成，PR 註明建議的合併順序。

## 做法

1. **先鎖舊行為**（在舊實作上通過後才改）：
   - `RenderQueueTests`：mesh 與 sprite 的 tint，4 個 channel × NaN／+inf／−inf，錯誤碼 `InvalidArgument` 與原訊息。
   - `RendererTests`：clear color 4 個 channel × NaN／+inf，原錯誤；沒有送出任何 frame。
   - `ModelRendererTests`：material tint（NaN）與 instance tint（inf），原錯誤碼與訊息；queue 沒有收到網格。
   - `MeshUpdateSmoke`（gpu）：SDL_GPU 的 pass clear color 4 個 channel 為 NaN 時，原錯誤 `SDL_GPU: invalid attachment clear value`。
2. **收斂**：`render/RenderTypes.hpp` 新增 `Engine::Render::IsFinite(const Color&)`（inline、noexcept），刪除 `RenderQueue.cpp`、`Renderer.cpp`、`SdlGpuRenderDevice.cpp` 的本地版本與 `ModelRenderer.cpp` 的 `Finite`。
   Renderer 的本地 `IsFinite(float)` 只被 Color 版使用，一起刪除；RenderQueue 與 SDL_GPU 的 `IsFinite(float)` 還有其他用途，保留。
3. **記錄理由**：`UiTypes.hpp` 的 `UiColor` 與 `RenderTypes.hpp` 的新函式註解寫明不合併型別、`UiValidation` 保留自己檢查的理由。
