# 2026-11-25 SDL 子批 R1b：Extract 的來源被替換（`v8-arch-gyo2-sdl-r1b`）

Owner：Kernel＋編排層。GYO2 主會話開的任務卡。分支 `claude/gyo2-sdl-r1b-extract-replace-8886f8`（開向 `gyo2`）。作者 Opus 5.5／high；設計審查 Opus／high（作者與審查者同模型：Fable 暫停）。

## 前提

Engine 要解決：`ReplaceWorld` 給新的 World 與新的 Registry（O-8），讀它的渲染 World 的 Registry 存著舊 Registry 的指標（DI-KS 37），換上就懸空；R1a 先擋成斷言。PvP 的大廳與重連要在同一個 Product 裡換前台 World，不關窗、不重傳 GPU 素材。

## 做了什麼

1. 事前宣告 `docs/architecture/target/v2/sdl-extract-replace-declaration.zh-Hant.md`：比 (A) 讀者一起重建、(B) 准許換來源、(C) 延後綁定；對照 Bevy（`Extract` 綁定第一次的 main world，換不了；讀檔＝同一個 world 裡 despawn／spawn＋同步通知）、Godot（RenderingServer 活過換場景）、Unity Netcode（新 Client World 或同一個 World 重連）。修訂 1 依設計審查（B1 S5 N4）改成「全部暫存、一起換進」、不繞過 `dynamicInsert`。使用者 2026-11-25「選 B，開始」。
2. Kernel（DI-KS 38）：`Registry::ReplaceExtractSource`（開之後一輪、改來源；受 `dynamicInsert` 擋）、`StagePlans`（建好留著）、`CommitPlans`（只搬移；`RegistryData` 的移動以 `static_assert` 確認不丟例外）；`BuildPlans` 的之後一輪＝兩者連著做。開輪的共通部分抽成 `OpenRound`。
3. 編排層（O-8、O-12）：拿掉 R1a 的斷言；替換時對每個直接讀者暫存，全部成功才在換上的那一步一起換進，任一失敗或例外丟掉所有暫存（`BuildNewFirst` 回 E2、舊的照跑；`DropOldFirst` 結束 Product）；`ExtractSourceSwaps` 登記在每個有 `extractFrom` 的 World，換上後加一。
4. 條文：Kernel 頁 DI-KS 13、26、37、38、RC 29；編排層頁 O-8、O-12、O-15、RC-O13（草案，最終文字合併前核准）。
