# GYO2 重建：R0b-3，守衛與 CI 政策的調整（`v8-arch-rebuild`）

日期：2026-11-14。Owner：架構（GYO2 重建會話）。分支 `claude/gyo2-mechanism`，PR #225 併入 `gyo2`（6b37078b）。決定與經過：[HANDOFF](../architecture/target/v2/HANDOFF.md)；逐項的判定變更：[R0b 報告](../architecture/target/v2/rebuild-r0b-report.zh-Hant.md)第 3 節與 3.1 節。

## 做了什麼

刪掉產品、工具與 render 之後，有三個本機測試與 CI 的第一個 job 失敗。這一批讓它們在「沒有產品與工具」的期間有明確的結果，產品與工具回來時檢查自動恢復。

- OS 邊界守衛：拿掉已刪檔案的名單項目與 render 的排除路徑；產品類的根（apps、tools、build/acceptance）沒有 C++ 時跳過並列出，engine、tests 是空的仍然報錯。
- 元件契約的測試：拿掉 render 的 GPU、shader 格式、裝置選項與 FRAMEWORK 的案例。
- CI 政策測試：沒有工具或產品 owner 時以註明理由的 skip 結束；拿掉掛在 gateway 與 render 上的判定；發佈 CLI 的 3 個案例改用測試自己的合成登記。
- 登記：保留名拿掉 `framework`；工具登記是空的時候，toolchain 那一列不含工具並印出說明，有登記卻漏了某個平台仍報錯。
- workflow：拿掉 kernel spike、render 的 GPU 測試步驟、shader 工具的原始碼雜湊；沒有工具的 toolchain 那一列跳過打包並印出原因。
