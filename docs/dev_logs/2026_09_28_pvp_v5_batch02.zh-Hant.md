日期：2026-09-28。Owner：`object_fps_pvp`。狀態：第02批完成並停止。

## 範圍與設計

使用者明確啟動 [第 02 批](../object_fps_pvp/plans/v5/02-player-model-and-locomotion.md)：
將遠端箱體換成現有女性人物、髮髻與右手手槍，完成下身 Idle／Jog 與上身持槍。
本批仍使用 v4 wire、20 Tick 射速、無限彈藥及原本 HP=0 行為；跳躍、換彈、
死亡／重生與三角色 v5 升版留第 03 批。完整動作呈現留第 04 批。

人物只消費 `SnapshotTimeline` 已取樣的位置、yaw、時間與世代，不新增移動預測。
每玩家保存自己的位移與動畫相位；本機視角、Mark23、射擊去重與權威膠囊保持原路徑。
第一次 Join 前載入模型／材質、組合骨架、建立 GPU instance 並提交一次成功暖機。
離開／重入清除人物實例的識別與相位，保留預備的 GPU 資源供下一次 Join。

只讀人物觀測附於成功 `PresentStatus::Presented` 的既有觀測，包含相位、路程、
骨骼遮罩、身體／附件／槍提交數及呈現 CPU 耗時。測試輸入和網路干擾只在 owner probe。

## Architecture Delta

1. 必要功能：遠端人物蒙皮、掛槍與位移步頻；現有 PvP 只提交箱體。
2. 現有壓力：複製的 Enemy renderer 依賴 Campaign snapshot／EnemyRig，不能作為玩家介面。
3. 改變範圍：PvP Client 增加 PlayerPresentation、玩家 JSON 與只讀呈現觀測；
   Client source 清單加入既有 CharacterPresentationDefinition。
4. Owner：全部新內容、probe、分析器與測試屬 `object_fps_pvp`。
5. 依賴方向：Client → 既有 Model／ModelRenderer／Render。Match／Gateway 不載入人物，
   Engine 不認識玩家、FPS 步頻或骨骼遮罩；不依賴 `object_fps_v2` 或 Editor。
6. 責任：動畫組合與素材校準留產品 Client；命中、移動與狀態裁決仍屬 Match。
7. 較小替代不足：把玩家註冊成 Enemy 會引入無關生命周期；整段搬 v2 的按時間播放
   又不能處理撞牆／hold。新增局部呈現器是必要切片，沒有通用動畫圖、IK 或新 subsystem。

Client 呈現 CPU／素材測試使用獨立 owner target，既有權威 domain CPU target 不增加
Model／SDL 依賴。專用內容仍透過產品 catalog／既有 staging，公共 build 不增加名稱分支。

### 步幅校準與限制

原始 Jog 約 0.933333 秒，reference geometry 縮放至 1.8 後 scale 約 1.01406。
每週期取 120 等分姿勢，以 `ball_l/r` 最低點上方 2.5 cm 且向後移動的樣本作
接地近似，得到 5.9424／5.97483 單位／秒；腳踝量測為 6.50763／6.37789，
兩種骨點並不等同鞋底接觸。原始數據見 `stride-calibration.log`。

產品資料保留 `reference_speed=3`，加入 `jog_stride_scale=2`：

```text
strideDistance = clipDuration × referenceSpeed × strideScale = 5.6
phaseIncrement = signedRenderedDistance / (referenceSpeed × strideScale)
```

因此實際速度 3 時，原始動畫播放率約 0.5，近地足趾退移速度約 2.9712／2.9874，
與 3 的差約 0.96%／0.42%。5.6 是完整 clip 的相位距離，不是一步腳印長度。
此校準沒有改 Arena 的移動速度，也不宣稱整週期零滑步、像素鞋底接地或 IK。
後退反向取樣，側移沿用 Jog；人物 yaw 仍跟瞄準，方向素材限制保留。

上下身以 `spine_01` 子樹遮罩組合；全局矩陣從組合後 local TRS 重建，髮髻與槍
跟同一 pose。腳底 anchor 固定來自 reference geometry，不隨動畫逐幀上下移動。
≥100 ms 的幀／時間線間隔、epoch、身分、相位重定位或位移跳變清步程。
Skipped 後下一次人物取樣重新錨定，不將最小化期間未呈現的移動累積成恢復步程。

不執行長測，不把本批短測當成 v5 完整驗收，不改 v4 歷史指南／回報表／穩定基線。
