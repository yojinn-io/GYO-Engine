## 4. 回答宣告的問題

- **「10% 對 µs 級是否適用」的資料**：在 Linux 實機上，M1 的四分位距比與去極值全距比約 1%（LN 0.7～1.3%、LD 0.1～2.4%），也就是排除單次偏離後，這台機器能分辨 2～3% 的差；但 10 次的全距比會被一次偏離（LN 第 0 次）拉到 35～44%。全距比在 10 次下對單次偏離不穩健。用哪個統計量、門檻多少，由使用者在 U12／之後的宣告定。
- **Mac 上容器不穩，是 VM 還是容器本身**：同一份 ELF、同一映像，MD 的四分位距比在多數指標是 LD 的 2.7～42 倍（M1 golden-all p95 4.1% 對 0.5%、match p95 4.5% 對 0.1%、host p95 14.2% 對 0.4%、M3 17.9% 對 6.6%、M7 4.3% 對 0.6%、RSS 3.3% 對 0.5%；例外 long4 p95：MD 1.6% 對 LD 2.0%）；LN↔LD 顯示容器化本身只加少量雜訊（§2.2）。**資料指向 VM（Docker Desktop）與 Mac 這台機器，而不是容器化本身**（MD↔LD 同時差 CPU 型號與時段，不能完全歸給 VM）。
- **Mac 原生能否取代 Linux 實機**：只看穩定度，MN 的 M1、M7 四分位距比 1.1～4.4%（安靜時段）；RSS 不行（17.1%）。前一張卡的本機白天兩組（5 次，參考欄）全距比 10.2～38.4%，安靜與否影響很大。
